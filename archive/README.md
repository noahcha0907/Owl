# Historical implementations

`owl-flight/` preserves earlier shader and JavaScript experiments. These files retain their original contents and may refer to the old project layout. They are records, not active modules.

`owl-flight/shader-original.glsl` is the preserved original backup and must remain byte-identical to [shaderRef.glsl](../references/shaders/shaderRef.glsl).

The active effect is in [effects/](../effects/), with its browser entry in [app/](../app/). Current recreation instructions are in [the guide](../docs/PHANTOM_OWL_RECREATION.md).
